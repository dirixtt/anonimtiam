# Анонимный Telegram-бот: Vercel + Supabase

Telegram присылает обновления в Vercel Function через webhook. Пользовательский материал
копируется владельцу и назначенным им субадминам, где появляются данные автора и кнопки
«Опубликовать» / «Отклонить». Supabase хранит состояние заявки и защищает от повторной
публикации.

## Что видит владелец

Владелец и субадмины видят содержимое заявки, имя автора, `@username` (если он установлен)
и числовой Telegram ID. Эти данные не публикуются в канале. Пока заявка ожидает решения,
имя, username и ID находятся в Supabase; после одобрения или отклонения они автоматически
удаляются из базы. Текст и файлы в Supabase не сохраняются — модераторы видят копию в Telegram.

Команда `/start` заранее и прямо объясняет пользователю эту модель приватности.

После изменения состава модераторов новые заявки отправляются актуальному списку. Уже
разосланные старые заявки удалённый субадмин может видеть в своей истории Telegram, но его
кнопки перестают работать сразу после удаления из списка.

## 1. Supabase

1. Создайте бесплатный проект на Supabase.
2. Откройте **SQL Editor**.
3. Выполните содержимое файла `supabase/schema.sql`.
4. В **Settings → API Keys** создайте или скопируйте серверный ключ формата
   `sb_secret_...`. Никогда не добавляйте его в публичный код или переменную с префиксом
   `NEXT_PUBLIC_`.
5. Скопируйте Project URL.

У всех трёх таблиц включён RLS, а доступ ролям `anon` и `authenticated` отозван. Сервер
Vercel обращается к ним только через секретный ключ.

## 2. Telegram

1. Создайте бота через `@BotFather` и получите токен.
2. Добавьте бота администратором канала с правом публикации.
3. Узнайте свой числовой Telegram ID.
4. Для публичного канала используйте `@channel_name`; для приватного — ID вида
   `-1001234567890`.

## Управление субадминами

Только главный владелец из `ADMIN_ID` может использовать команды:

```text
/admin_add 123456789
/admin_remove 123456789
/admins
```

Перед добавлением попросите будущего субадмина открыть бота и нажать `/start`, иначе Telegram
не разрешит боту отправить ему личное сообщение. Субадмины получают все новые заявки и могут
одобрять или отклонять их, но не могут управлять другими администраторами.

## 3. Vercel

Загрузите папку в GitHub и импортируйте репозиторий в Vercel. Framework Preset можно
оставить **Other**. Затем добавьте в **Project Settings → Environment Variables**:

```text
BOT_TOKEN
ADMIN_ID
CHANNEL_ID
TELEGRAM_WEBHOOK_SECRET
SUPABASE_URL
SUPABASE_SECRET_KEY
```

`TELEGRAM_WEBHOOK_SECRET` — самостоятельно созданная длинная случайная строка из букв,
цифр, `_` и `-`. После добавления переменных выполните повторный Deploy.

Проверка после деплоя:

```text
https://YOUR-PROJECT.vercel.app/api/webhook
```

URL должен вернуть JSON с `"ok": true`.

## 4. Подключение webhook

Скопируйте `.env.example` в `.env.local`, заполните как минимум `BOT_TOKEN`,
`TELEGRAM_WEBHOOK_SECRET` и полный `WEBHOOK_URL`, затем выполните:

```powershell
node scripts/set-webhook.mjs
```

Пример `WEBHOOK_URL`:

```text
https://YOUR-PROJECT.vercel.app/api/webhook
```

## Проверка кода

```powershell
node --test
```
